# Week 23 – Gráficas y nuevo dataset con CARLA Record/Play

Esta semana se generaron nuevas gráficas para analizar el comportamiento del vehículo y se grabó un nuevo dataset usando CARLA Record/Play, permitiendo repetir trayectorias y capturar datos de control de modo estable.

**Avances**
- Se generaron gráficas para analizar steer y throttle.  
- Se integró CARLA Record/Play para capturar datos reproducibles.  
- Se registró control (steer, throttle, brake) y comportamiento del vehículo.  
- Se corrigió el proceso de grabación para evitar desincronización de cámara/spectator.

**Pruebas realizadas**
- Grabación del escenario con `client.start_recorder()`.  
- Reproducción con `client.replay_file()` verificando consistencia.  
- Análisis posterior mediante scripts para graficar controles vs tiempo.

**Próximos pasos**
- Mejorar la estabilidad visual al reproducir trayectorias.  
- Generar gráficas adicionales para correlación entre avances rectos y valores de steering.  
- Preparar dataset final para entrenamiento.
