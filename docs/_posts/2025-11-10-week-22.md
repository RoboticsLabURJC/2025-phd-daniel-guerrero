# Generación de gráficas y nuevo dataset con CARLA Record/Play

Durante esta semana se avanzó en la **visualización y análisis de datos** obtenidos de las grabaciones previas, además de realizar nuevas pruebas de adquisición con el sistema **Record/Play de CARLA**.

**Avances técnicos**
- Se generaron **gráficas 2D y 3D** para visualizar el comportamiento de las variables de control (`steer`, `throttle`, `brake`) a lo largo del tiempo y analizar la distribución de los datos.  
- Se grabó un **nuevo dataset** utilizando la funcionalidad de **CARLA Record/Play**, permitiendo repetir escenarios de conducción controlados y capturar las secuencias para entrenamiento posterior.  
- Se identificó un problema en la **cámara del simulador**: durante la reproducción (`replay`), la vista parece **desacoplada del vehículo**, lo que impide mantener una perspectiva coherente del entorno. Este comportamiento sugiere que el *spectator* no se está sincronizando correctamente con el actor principal durante la grabación o reproducción.  
- Se están evaluando posibles soluciones, incluyendo la fijación explícita de la cámara al `vehicle_actor` dentro del callback del *replay client*.

**Próximos pasos**
- Corregir el problema de seguimiento de cámara en el modo Record/Play.  
- Continuar con la generación de gráficas de análisis para el dataset recién grabado.  
- Evaluar la calidad y balance de los datos capturados para preparar un nuevo ciclo de entrenamiento.
