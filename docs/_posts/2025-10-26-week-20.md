# Prueba de PilotNet, captura con OpenCV y balanceo pendiente

Durante esta semana trabaje con PilotNet en lugar de MobileNet en el simulador CARLA y el seguimeinto del carril mejoro, comprobe que el vehículo mantiene el carril de forma estable bajo condiciones controladas.  
El modelo fue evaluado utilizando secuencias capturadas con el nuevo grabador, y se verificó que los valores de `steer`, `throttle` y `brake` se sincronizan correctamente con las imágenes.

Para mejorar el flujo de trabajo de adquisición, se implementó el código para capar  las imágenes con OpenCV.

**Avances técnicos**
