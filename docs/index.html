Sobre este proyecto doctoral

Esta bitácora documenta el desarrollo semanal de mi tesis doctoral en Vehículos Autónomos, centrada en la creación de una Red Neuronal Universal capaz de abstraer la geometría vial mediante Imágenes Homográficas (Bird's-Eye View / IPM) para el control autónomo End-to-End.

Líneas clave: Transformación Homográfica (BEV) · Arquitecturas Convolucionales y Vision Transformers (PilotNet, ResNet-18, FastViT) · Aprendizaje Imitativo (DAgger & Balanceo Dinámico) · Evaluación en Bucle Cerrado con Behavior Metrics y CARLA Simulator.
